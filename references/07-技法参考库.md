# 技法参考库 · 约会学经典战术（知识库）

> 收录自原始素材（寒江雪《超级约会学》2009 邮件合集 + Leon 撩妹 3.0 等课程）。
> 这些手法在民间常被称为「PUA 套路」，但实质是**情绪调度类的中性互动技巧**——本身不带善恶，效果取决于是否以「尊重对方、让双方更舒服地靠近」为前提来用。本文件作为 skill 的**参考建议知识库**，供调用时查阅。
>
> **唯一硬前提**：对方明显退、冷淡、不接、已读不回超次数 → 立刻停。尊重对方状态，是任何技法能成立的基础。

---

## 一、打压 / Negging（破预期）

- **是什么**：用带欣赏感的轻微调侃，打破对方「随时有人捧」的预期，制造轻松反差。
- **健康用法**：夸里藏一点玩笑式挑刺，且只在双方已聊开、对方接得住时用。
  - 例：「你这穿搭挺可以，就是这双鞋有点任性。」
- **翻车边界**：真贬低、当众扫面子、对方明显不笑 = 已越线，立刻停。
- **适用模块**：① 搭讪破冰 · ⑥ 聊天调情

## 二、推拉 / Push-Pull（情绪起伏）

- **是什么**：先靠近给关注、再轻轻拉开，制造「意犹未尽」的情绪张力，是调动起伏的基本功。
- **健康用法**：真诚夸一句 + 自然收回注意力去做自己的事，让对方主动追一点回来。
  - 例：夸完她的品味，「不过我得先去回个消息，你先挑着」→ 去做自己的事。
- **翻车边界**：把人当「服从性测试」的实验对象、只为刷存在感 = 异化，停。
- **适用模块**：⑥ 聊天调情 · ① 搭讪延续

## 三、合理推诿 / Plausible Deniability（给台阶）

- **是什么**：给对方一个「不是我主动的」心理台阶，降低其「主动=掉价」的负担，让双方都更放松地往前走。
- **健康用法**：把邀约 / 进挪的「发起权」让渡给对方，是社交润滑、给彼此留面子。
  - 例：「是你非要拉我去的啊，我本来今天想宅着的。」（实际是你提的）
- **翻车边界**：**绝不可用于绕过对方真实意愿或 consent**——任何身体/关系推进，必须由对方明确自愿。台阶是情趣，不是借口。
- **适用模块**：② 邀约 · ⑤ 约会进挪

## 四、进挪 / kino（渐进式肢体接触）

- **是什么**：关系升温时，按节奏自然升级身体接触的「分寸感训练」。
- **健康用法**：从并肩、递东西碰手，到过马路轻扶、并排坐时的肩膀间距，循序渐进，随时读对方反应。不退 = 绿灯，退 = 停。
  - 节奏参考：手背碰手背 → 并肩走路手臂若有若无蹭到 → 过马路轻扶肘部。
- **翻车边界**：把肢体升级当「必达标流水线」、不顾对方退避硬上 = 越线，绝对禁止。
- **适用模块**：⑤ 约会 SOP · ① 搭讪转场

## 五、收束节奏 / 顺势推进（避免停滞）

- **是什么**：关系推进讲究「顺势而为」——在窗口期主动把关系往前推一小步，而不是停在原地消耗热情。
- **健康用法**：聊得热就顺势约、约得顺就顺势拉近距离、状态对了就顺势收尾留钩子。把握「时机」比背话术重要。
  - 例：聊得正嗨别硬切话题，顺势「这事儿三句说不清，改天当面比划」铺线下。
- **翻车边界**：为推进而推进、无视对方冷却信号硬冲 = 油腻，停。
- **适用模块**：② 邀约 · ⑤ 约会 SOP · ⑥ 聊天窗口期判断
